# Working in this repository

`ikigai-layers` is an ikigai layer host: shared spaces between participants, each defined by
configuration (an access model, closed SHACL shapes, an egress context and per-layer grants),
plus the `ikigai-layers` binary that derives a door's enrollment. These rules are for every
agent and every person working here. `CLAUDE.md` is a link to this file.

- Read [ACCESSIBILITY.md](ACCESSIBILITY.md) before any change to output people read: messages,
  pages, terminal text. Here that is write answers, plain listings, refusals, onboarding
  diagnostics and the binary's output.
- Security reports go through GitHub private vulnerability reporting, never a public issue.
- Every change lands through a pull request with green CI.
- Use American spelling in everything you write: code comments, docs, commit messages and pull
  requests.
